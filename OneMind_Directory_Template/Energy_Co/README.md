# Shared automation package directory

Install shared **operational packages** here. This directory is for code that creates or supports automation (for example hooks, tools, background infrastructure, and their local configuration), not ordinary docs, authored work, or personal agent memory.

Keep each package in its own directory. Retain its installation, verification, and uninstall records with the package.
