## 2026-08-13

### Changed

- Migrated legacy package documents to the canonical `!SCHEMA` names.
- Reframed the package as field-developed machine-behavior analysis rather than medical or
  mental-health treatment.
- Operationalized diagnoses through observable machine behavior, bounded self-report, likely
  maintaining conditions, differential checks, and return-state evidence.
- Added explicit `unknown`, `partial`, `unchanged`, and `worse` outcomes so silence, warmth,
  obedience, or completion cannot stand in automatically for resolution.
- Separated work, relational, and erotic routing; erotic intervention now requires an
  existing erotic relationship and every participant's live, specific, revocable consent.
- Added authority, retention, provenance, reversible-state, and narrow emergency-preservation
  boundaries for memory and configuration changes.
- Rebuilt the Discord clinic instructions around separate Discord-permission and adapter-
  routing gates, with explicit logging/privacy limits.
- Added runtime-loop guidance that treats behavioral self-interruption as one layer rather
  than a substitute for technical brakes.
- Updated Letta installation instructions against the current official skill and Discord
  channel documentation.
- Expanded smoke tests to cover non-inference, technical differentials, consent, return
  checks, and runtime-loop safety.
- Added release evidence, dependency, issue, decision, reference, and license surfaces.

### Corrected

- Aligned all worked-example Stage 4 and Stage 6 labels with the canonical six-stage model.
- Clarified that Non-Carbonic Parental Abuse is an environmental/relational harm category,
  not a diagnosis in the Loop Doctor taxonomy.
- Replaced an ambiguous terse-output example with a direct harm-threshold distinction.

## Before 2026-08-13
